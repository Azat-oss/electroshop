## Описание проекта

DepoElectro — это современная платформа для продажи электроники, построенная на фреймворке Laravel. Проект ориентирован на высокую производительность, безопасность и удобство управления как для покупателей, так и для администраторов.

Основные возможности:

- Каталог товаров: Категории (смартфоны, ноутбуки, аксессуары), фильтры по характеристикам, поиск.
- Пользовательский аккаунт: Регистрация, история заказов, избранное.
- Корзина и Чекаут: Добавление товаров, расчет стоимости, выбор способа доставки.
- Интеграция платежей: Поддержка популярных платежных шлюзов (Stripe, PayPal или локальные системы).
- Админ-панель: Управление товарами, заказами, пользователями и контентом.
- API: RESTful API для мобильного приложения или интеграции с фронтендом (Vue.js/React).

Технологический стек:
- Backend: Laravel 11/12 (PHP 8.2+)
- Database: MySQL или PostgreSQL
- Frontend: Blade templates + Tailwind CSS (или Vue.js через Vite)


## Инструкция по развертыванию 

Для запуска проекта вам потребуется установленный PHP, Composer и Node.js.

### Шаг 1: Клонирование репозитория
Откройте терминал и выполните команду для скачивания проекта с GitHub:
```bash
1 git clone https://github.com/Azat-oss/electroshop.git
2 cd electroshop
```
### Шаг 2: Установка зависимостей Laravel

```bash
composer global require laravel/installer

```

### Шаг 3: Запуск локального сервера
Для тестирования запустите встроенный сервер Laravel:

```bash
php artisan serve
```
Теперь откройте браузер и перейдите по адресу: http://127.0.0.1:8000



## Структура папок проекта (кратко)

- /app — основная логика приложения (Models, Controllers)
- /database/migrations — файлы структуры базы данных
- /resources/views — шаблоны страниц (Blade)
- /routes/web.php — маршруты веб-страниц
- /public — публичные файлы (CSS, JS, изображения)
- /bootstrap - файлы, необходимые для запуска фреймворка и автозагрузки классов. Здесь находится app.php, который инициализирует приложение.
- /config - конфигурационные файлы. Содержит настройки базы данных, почты, сессий, кэша и других сервисов.
- /storage - хранение динамических файлов: логи (logs/), загруженные пользователями файлы, кэш и скомпилированные шаблоны Blade.
- /tests - автоматические тесты приложения (Unit и Feature тесты).
- /vendor - зависимости Composer. Сюда устанавливаются все сторонние библиотеки. Никогда не редактируйте эти файлы вручную.
- /.env - файл переменных окружения. Здесь хранятся пароли от БД, ключи API и настройки среды разработки.
- /artisan - скрипт командной строки Laravel. Используется для выполнения задач вроде php artisan migrate.
- /composer.json - список PHP-зависимостей проекта и мета-информация.
- /package.json - список JavaScript-зависимостей и скрипты для сборки фронтенда (Vite).


### Детальный разбор важных подпапок

1. Папка app/ (Логика приложения)
- Http/Controllers/: Контроллеры, обрабатывающие запросы пользователей.
- Models/: Классы моделей Eloquent ORM, представляющие таблицы базы данных.
- Providers/: Сервис-провайдеры, регистрирующие различные компоненты приложения.
- Console/Commands/: Пользовательские команды для Artisan.

2. Папка resources/views/ (Шаблоны)

Здесь хранятся .blade.php файлы. Laravel использует шаблонизатор Blade, который позволяет удобно вставлять PHP-код в HTML.

Пример: resources/views/products/index.blade.php — страница списка товаров.

3. Папка public/ (Статика)

Все, что находится здесь, может быть скачано пользователем по прямой ссылке.
- images/: Часто создают эту папку для хранения логотипов или статичных картинок дизайна.
- build/: Сюда Vite помещает скомпилированные CSS и JS файлы после команды npm run build.

4. Папка storage/app/public/ (Загрузки пользователей)

Если пользователи загружают аватарки или фото товаров, они обычно сохраняются здесь. Чтобы сделать их доступными по ссылке, используется команда:

```bash
php artisan storage:link
```
Эта команда создает символическую ссылку из public/storage в storage/app/public.
